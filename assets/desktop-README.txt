LAST HARVEST

The game's data lives in data/game_data.pak beside the game. When it's missing,
the game downloads it from its release on first start; with no connection, put
game_data.pak from the same release as this package in the data folder here.

Start the game with last-harvest (last-harvest.exe on Windows, Last Harvest on
macOS). On macOS, the first start needs a right-click on it, then Open, as the
build isn't signed; if macOS still refuses, allow it under System Settings >
Privacy & Security.

It opens one window and plays as on a phone: the keyboard, a gamepad or the
mouse, which works the on-screen controls. LAST_HARVEST_WINDOWS=2 opens a
window per screen instead, as on the handheld.

Keys: arrows walk, A and X turn, Z turns around, Q aims a grenade, 1 shows the
map, Enter pauses. The manual covers the rest:
https://kylejameswalker.github.io/last-harvest/manual.html

The data folder also takes mods, cards, props and maps; see data/README.txt.
