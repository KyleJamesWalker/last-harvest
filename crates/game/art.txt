# Sprites cut from the Zombie Apocalypse Tileset reference sheet; build.rs packs them into one texture.
#
#   NAME  frame ; frame ; ...
#   cell C R [W H] [xN] [-C,R] [C,R<C2,R2] [/W,H]
#        grid cells with the gaps removed; xN repeats N frames to the right, -C,R clears a cell,
#        C,R<C2,R2 draws cell C2,R2 beneath C,R, /W,H crops the result to W x H pixels, and
#        key=RRGGBB,... clears those colors where they touch the edge, to drop a baked-in ground
#   px X Y W H                       raw reference pixels, for sprites that straddle the grid
#   solid W H                        opaque white, for tinted particles
#   blank W H                        clear, for the sprite editor's scratch space
#   png FILE [xN]                    a picture in this folder, cut into N frames side by side
#
# A line may end with how the sprite stands in the 3D view: @prop DEPTH (upright, extruded back), @fold ROWS (the
# rows above ROWS laid flat as the roof, the rest upright as the front),
# @slab HEIGHT (flat as a roof that high, for sprites drawn from above), @figure (turns to the camera)
# or @ground (flat). Without one, buildings reach back over their solid rows and small things are thin.
#
# A sprite saved from the editor as assets/private/sprites/NAME/0.png, 1.png and so on replaces its frames here,
# and a folder there with no line here adds a new sprite. A paints.txt there packs its frames once in each coat.
