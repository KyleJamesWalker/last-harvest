# Every powerup the level-up cards can offer. Change a number and rebuild; nothing else needs to change.
#
#   slots weapons N | slots passives N     how many of each a run can carry
#   start DIFFICULTY ID ...   the weapons a run carries at easy, normal or hard; each must be `unlock start`
#   grenades N          grenades every run starts with, before a grenade belt
#   finds N             the most powerups one run can find
#   first_level N       money for the first level-up; each after costs about 1.35 times the last, plus 2
#
#   [id]                start of a powerup; the id is how the save and the code know it
#   name    Text        the card's title
#   kind    weapon | passive | filler      fillers are offered only when nothing else is left; the book needs one
#   does    behaviour   for weapons, which behaviour it fires with; defaults to the id, so a copy
#                       under a new id with `does scythe` is a second scythe with its own numbers
#   zone    ahead | around | behind | map
#   icon    SPRITE      the card's picture, a name from art.txt; defaults to ICON_<ID>
#   unlock  start | kills N | night SECONDS | level N | nights N | dawns N
#           kills and nights add up over every run; night and level are the best single run.
#           Anything but `start` only becomes findable: a level-up may then offer it on a FOUND card,
#           and taking that card unlocks it for good. A find needs a free slot of its kind.
#   find    CHANCE      how often a level-up offers it as a find, 0 to 1; 0.25 when left out
#   after   MINUTES     the earliest it can be found in a night; 0 when left out
#   chest   (no value)  found only in the chest a horde's leader drops; a chest holds a find whenever one is waiting
#   effect  NAME        for weapons, the effects.txt effect it plays in place of its behaviour's own
#   bullet  NAME        for weapons that shoot, the effects.txt effect its bullets fly as
#   sound   NAME        for weapons, shot, blast, slash, zap, bark or throw in place of its behaviour's own
#   blurb   Text        the card's line when the powerup is new
#   max     N           highest level
#   STAT    v1 v2 ...   the value at each level, from level 1; a short list repeats its last value
#
# Weapon stats, and their value when left out:
#   cooldown 1   seconds between attacks       damage 0     per hit, or per second for fire and tacks
#   count 1      bullets, crows, dogs...        range 100    how far it reaches or looks, in pixels
#   area 20      radius or width, in pixels     pierce 0     extra zombies a bullet goes through
#   speed 200    pixels per second              duration 1   seconds a pool, trap or burn lasts
#   spread 30    degrees across a fan of shots  knockback 30
#   slow 0       fraction of speed taken away
#
# Passive stats are the total at that level, and passives add together. Write the ones that scale with a
# percentage (+10% or -8%): damage, cooldown, speed, magnet, area, reach, greed, knockback, view, recharge,
# blast. The rest are plain numbers: max_hp, heal, armor, regen (health a second), crit and luck (chances,
# 0 to 1), pierce, revive, grenades, cluster, drums (seconds between barrels coming back), refill, money.
