# Every powerup the level-up cards can offer. Change a number and rebuild; nothing else needs to change.
#
#   slots weapons N | slots passives N     how many of each a run can carry
#   start DIFFICULTY ID ...   the weapons a run carries at easy, normal or hard; each must be `unlock start`
#   grenades [DIFFICULTY] N   grenades a run starts with, before a grenade belt; without a difficulty, for all three
#   finds N             the most powerups one run can find
#   first_level N       hearts for the first level-up; each after costs about 1.35 times the last, plus 2
#
#   [id]                start of a powerup; the id is how the save and the code know it
#   name    Text        the card's title
#   kind    weapon | passive | filler      fillers are offered only when nothing else is left; the book needs one
#   does    behaviour   for weapons, which behaviour it fires with; defaults to the id, so a copy
#                       under a new id with `does scythe` is a second scythe with its own numbers
#   zone    ahead | around | behind | far
#   icon    SPRITE      the card's picture, a name from art.txt or a player's prop, PROP_<ID>; defaults to ICON_<ID>
#   unlock  start | kills N | night SECONDS | level N | nights N | dawns N | breakers N | breaker_dawns N
#           kills and nights add up over every run; night and level are the best single run.
#           breakers counts nights with a level breaker, and breaker_dawns those of them survived until dawn.
#           Anything but `start` only becomes findable: a level-up may then offer it on a FOUND card,
#           and taking that card unlocks it for good. A find needs a free slot of its kind.
#   find    CHANCE      how often a level-up offers it as a find, 0 to 1; 0.25 when left out
#   after   MINUTES     the earliest it can be found in a night; 0 when left out
#   chest   (no value)  found only in the chest a horde's leader drops; a chest holds a find whenever one is waiting
#   player  ID          one player card's own: offered, found and counted only when [ID] is picked; every player's
#                       when left out. Not for fillers, nor the start lines above; a player card's start can name it
#   effect  NAME        for weapons, the effects.txt effect it plays in place of its behaviour's own
#   bullet  NAME        for weapons that shoot, the effects.txt effect its bullets fly as
#   sound   NAME        for weapons, the sound group it plays in place of its behaviour's own: NAME.ogg, NAME-2.ogg
#                       and on in the sounds. shot, blast, slash, zap, bark and throw have a voice of their own;
#                       any other group with no clips plays the behaviour's own
#   sound_every N       for weapons, plays its sound once every N rounds, for a recording of several; a burst starts
#                       again from its first round. 1 when left out
#   sound_after NAME    for weapons, a sound group that follows its sound sound_delay seconds later, such as a bolt
#                       worked after a shot; one with no clips plays nothing
#   sound_delay SECONDS for sound_after, how long it waits; 0.4 when left out
#   sound_hit NAME      for weapons, a sound group its shots, pops and throws play where they hit or land, in place
#                       of the thud or boom; one with no clips plays nothing
#   aim     nearest | ahead | behind | around | strongest | farthest | random     for `does gun` and `does blade`,
#                       where it looks for a target in range: strongest has the most health left; nearest when left
#                       out. A blade cuts everything within area across spread degrees, 360 all round
#   homing  DEGREES     for `does gun`, how fast its shots turn toward their target, onto the nearest when it falls
#   explode PIXELS      for `does gun`, the blast each shot pops in where it ends, playing effects.txt's [pop]
#   arc     PIXELS      for `does gun`, how high its shots climb before they dive onto their target; flying over
#                       zombies and cover while high. 0 when left out
#   through 1 | 0       for `does gun`, its shots pass through every zombie but the one they were fired at; 0 when left out
#   lands   blast | fire | flare | tacks     for `does lob`, which throws count at a crowd within range, what it does
#                       where it lands, with damage, area, duration and slow; blast when left out. It flies as its
#                       bullet effect, the grenade when left out, and plays its effect where it lands. A blast
#                       lands clear of the thrower's hurt, moved out along the throw when the crowd is closer
#   pattern fan | ring | spray | burst     for `does gun`, how count shots spread: evenly across spread, evenly all
#                       the way round, or at random across spread; fan when left out. A burst, for `does gun` and
#                       `does pistol`, fires them one after another, gap seconds apart, each aimed as it fires,
#                       then waits its cooldown
#   targets same | each    for a burst, which zombies its shots go to: each where its aim finds, or the first
#                       there and each after the nearest in range and clear line of fire not yet shot in this
#                       burst, all the way round, one shot again only once every one has been; same when left out
#   outside N           for a burst that `targets each`, how far in pixels its later shots reach a zombie outside
#                       the view; its whole range when left out, 0 for only what's in view
#   kick N | punch N | shake N    for weapons, each attack's camera kick back, punch in and screen shake; none when left out
#   flash R G B REACH SECONDS     for weapons, a flash of light on each attack: its color, above 1 for brighter than
#                       white, how far it lights in tiles, and how long; none when left out
#   blurb   Text        the card's line when the powerup is new
#   max     N           highest level
#   STAT    v1 v2 ...   the value at each level, from level 1; a short list repeats its last value
#
# Weapon stats, and their value when left out:
#   cooldown 1   seconds between attacks       damage 0     per hit, or per second for fire and tacks
#   count 1      bullets, crows, dogs...        range 100    how far it reaches or looks, in pixels
#   area 20      radius or width, in pixels     pierce 0     extra zombies a bullet goes through
#   speed 200    pixels per second              duration 1   seconds a pool, trap or burn lasts
#   spread 30    degrees across a fan of shots  knockback 30
#   slow 0       fraction of speed taken away   gap 0.1      seconds between a burst's shots
#   soak 0       seconds each hit, bullet or burner's flame soaks a zombie in fuel; not pools, traps or throws
#   soak_burn 0  how many times hotter and longer fire burns a zombie it soaked, from 1
#
# Passive stats are the total at that level, and passives add together. Write the ones that scale with a
# percentage (+10% or -8%): damage, cooldown, speed, magnet, area, reach, greed, knockback, view, recharge,
# blast. The rest are plain numbers: max_hp, heal, armor, regen (health a second), crit and luck (chances,
# 0 to 1), pierce, revive, grenades, cluster, drums (seconds between barrels coming back), refill, money (hearts).
