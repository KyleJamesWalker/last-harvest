# records meet, at the end of every night and when a save loads. A store's own achievement list must use these ids.
# Mods can't change this file.

#   [id]          start of an achievement: lowercase letters, digits and _, never changed once a store has it
#   name  Text    its title
#   when  kills N | night SECONDS | level N | nights N | dawns N | breakers N | breaker_dawns N
#                 as powerups.txt's unlock, over every difficulty's records: kills, nights, dawns and breakers add
#                 up, night and level are the best single run
